make.fun entry for [Till Firmware Do Us Part](https://make.fun/c/u-azazex-till-firmware-do-us-part-32172929) — a single wedding vow a robot speaks at its own wedding: the classic vow ("in sickness and in health, for richer, for poorer") retold in machine terms, closing on a machine's version of "till death do us part".

## Run

```sh
node main.ts
```

It writes the entry to `/output/entry.txt` (one sentence, 122 characters).

## The entry

> I vow to love you in sickness and in low battery, for richer code and for poorer signal, until my last fan stops spinning.
